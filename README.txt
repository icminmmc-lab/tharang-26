THARANG'26 EVENT FINDER
========================

Files:
- index.html
- style.css
- script.js

Run:
1. Keep all three files in the same folder.
2. Open index.html in Chrome.
3. For online hosting, upload all three files to your web hosting.

Features:
- Mobile-first student interface
- THARANG'26 navy/gold design
- Search by event name/code
- Group / Individual / Online filters
- Event detail screen
- Venue, time and block/floor
- Responsive design

Event data is based on the uploaded THARANG'26 Event Room Assignment.
