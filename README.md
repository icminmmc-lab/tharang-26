# THARANG'26 Event Finder — Logo Edition

## Included
- index.html
- style.css
- script.js
- college-logo.png
- tharang-logo.png

## Run
Open `index.html` in Chrome or Edge.

## Website flow
QR code → website → search/filter event → click event → venue + time + block/floor.

The two uploaded logos are already included and referenced locally, so the website does not need an internet connection for the logos.

## Update event information
Edit the `events` array in `script.js`.

Each event has:
- code
- name
- type
- time
- venue
- block

## Deploy
Upload all five files to any static hosting service. The QR code should point to the deployed `index.html` website URL.
